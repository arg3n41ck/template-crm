- **logger**
-
- A simple logging utility that provides methods for standardized logging of informational messages, warnings, and errors to the console.
-
- **Functionality:**
- - Offers three logging methods: `info`, `warn`, and `error`.
- - Each method prefixes the logged message with a corresponding label (`[INFO]`, `[WARN]`, `[ERROR]`) to indicate the type of log.
- - Utilizes the native `console` methods (`console.info`, `console.warn`, `console.error`) for output.
-
- **Methods:**
- - `info(message: any): void` - Logs informational messages with an `[INFO]` prefix.
- - `warn(message: any): void` - Logs warning messages with a `[WARN]` prefix.
- - `error(message: any): void` - Logs error messages with an `[ERROR]` prefix.
