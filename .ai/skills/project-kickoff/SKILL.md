# Project Kickoff

Read AGENTS.md and docs/PROJECT_BRIEF.md if present. Extract audience, core scenarios, explicit stack, non-goals and acceptance criteria. Ask only about consequential ambiguity. Keep existing stack. Record a short task contract in .codex-harness/tasks only for multi-step work; do not create speculative product modules.
